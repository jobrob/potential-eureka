# Sprint A3 — Light policy iteration (optional, escalate-only)

> Refit `V` on trajectories generated by the *current* `leaf_value="learned"`
> search agent (better-than-heuristic driving), so V can credit lines the
> heuristic never demonstrates. One bounded loop with a hard stop rule — **not**
> open-ended self-play (the 8C collapse failure mode). **Run only if A2 does not
> comfortably clear Rung 2.**

## Goal

Close the "V can't exceed the policy that generated it" gap (options doc Cons/risks)
with **1–2 rounds** of light policy iteration: generate fresh value data with the
A2 learned-leaf `LookaheadAgent`, re-fit V on old+new data, re-gate, and **stop
when the held-out gate stops improving**.

## Scope

**In:**
- A driver that reuses `gen_value_data.py` (A1) with the **search agent** (not the
  heuristic) as the trajectory policy, on the same TRAIN/VAL bands.
- A refit of V (re-run `train_value.py` on the union of A1 + A3 data) and a
  re-gate via the extended `eval_search.py`.
- A documented **stop rule** and an orchestrator that applies it.

**Out:**
- Any new model architecture, codec change, or search change (A3 reuses A1's
  trainer + A2's agent verbatim — only the *trajectory policy* and the *dataset
  union* change).
- More than 2 iterations (hard cap).
- 4p / opponents.

## Deliverables (concrete files / functions)

- **`experiments/value_iterate.py`** — the bounded policy-iteration orchestrator:
  - parameterize `gen_value_data.py`'s generator policy so seat 0 can be a
    `LookaheadAgent(leaf_value="learned", value_model_path=<current V>)` instead of
    `HeuristicAgent` (a `--policy {heuristic,learned}` + `--value-model` knob added
    to `gen_value_data.py`; the learned policy is the same agent A2 ships).
  - per iteration: (1) generate new MC value data with the current V's search
    agent; (2) refit V via `train_value.py` on the **union** of all data so far
    (old A1 + every prior A3 round) — guards against catastrophic forgetting of the
    states the heuristic covered; (3) re-gate on the held-out 900_000+ band.
  - apply the **stop rule** (below) and preserve the best-gating V checkpoint.
  - wrap in `run_main("value_iterate", main)`.
- Reuse A1's `train_value.py` and A2's `eval_search.py` unchanged (no new trainer
  or eval).
- **`tests/test_value_iterate.py`**: the union-of-data invariant (round N trains on
  ≥ all prior rows); the stop rule fires on no-improvement; the best checkpoint is
  the one preserved.

## Stop rule (explicit)

Let `gate(V) = (worst_case_limit1_spins, rounds_to_finish)` on the held-out band.
Run at most **2** iterations. **Stop after any iteration whose `gate` does not
strictly improve on the previous iteration's `gate`** (rounds-to-finish must
decrease OR worst-case limit-1 spins must decrease, with neither regressing).
Keep the best-gating V. Rationale: a one-step no-improvement rule + a hard 2-cap
is the minimal bounded form of policy iteration — it cannot spiral into the
unbounded self-play collapse the 8C saga showed (memory `8c-production-collapse`),
and it never ships a V that gates worse than A2's.

## Success criteria (measurable, on the shared eval)

- **Rung 4 (README):** if A3 runs, the final V **beats the A2 V** on the held-out
  gate (lower rounds-to-finish and/or lower worst-case limit-1 spins), and each
  retained iteration strictly improved until the stop rule fired.
- **No regression:** the final V still passes A2's Rung 1 floor (corner skill
  intact) and never gates worse than A2's V (best-checkpoint preservation
  guarantees this).

## Risks & mitigations

- **Distribution shift / forgetting** (V refit only on search states forgets
  heuristic-covered states). → Train on the **union** of all data, not just the
  newest round.
- **Compounding bias / collapse** (the 8C pathology). → The hard 2-iteration cap +
  strict-improvement stop rule + best-checkpoint preservation make collapse
  impossible to ship; a non-improving round is discarded.
- **Cost** (the search agent is ~100× the heuristic per move for data generation).
  → Reuse A2's `top_k`/`sim_budget` branching control on the trajectory agent (S2
  showed `top_k=6` is "free accuracy"), and keep iterations ≤ 2.
- **A3 may be unnecessary.** → It is **escalate-only**: skipped entirely if A2
  clears Rung 2. Documented as conditional in the README.

## Dependencies

- **A1** (`gen_value_data.py`, `train_value.py`) and **A2** (the shippable
  `leaf_value="learned"` agent + extended `eval_search.py`) — hard dependencies.
- No new infrastructure beyond the orchestrator.

## Rough effort

~0.5 sprint, and **only if triggered**. It is glue over A1+A2 plus the stop-rule
orchestration; no new model or eval code.
