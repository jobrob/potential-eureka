L05 - Honest boundary

Track and starting-seat localization cannot be reconstructed.

The historical multi-ruler schema stores one aggregate for each contender, ruler, and seat-count cell. It records the track band and game seed, but not individual race outcomes. L0 can therefore map generation, seed, selected checkpoint, legacy milestone, ruler, seat count, and track band.

Missing from historical evidence.
Per-race starting position, per-track result, and track-family result are not recoverable. The next live benchmark must persist track_seed, track_family, game_seed, focal_starting_seat, finish position, and placement reward for every race.
