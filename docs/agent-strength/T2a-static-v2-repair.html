03 · Predeclared decision rules

Adopt only a useful speed repair.

  • Semantic gate.
    V1 frozen contracts pass; V2 cache keys separate rounds/hands; certain-spin veto and safe-slot reservation pass; both heuristic Stress guards return legal plays; deterministic full-game smoke passes.
  • Racing-speed gate.
    Aggregate mean terminal rounds must decrease versus post-T1a V1, with no track family slower by more than 2%.
  • Strength gate.
    Aggregate focal placement reward for repaired heuristic and search must not fall by more than 0.03 each. Report all family × seat × opponent cells because static matchups are non-transitive.
  • Compute gate.
    Search planning milliseconds per move must not regress by more than 10% in aggregate; total wall time is reported as a secondary noisy check.
  • Stop rule.
    If smoke violates legality/determinism or exceeds the expected bounded runtime, stop before the full map. If the full map fails a gate, retain V1 as the adopted ruler and report which V2 component needs redesign.

Why an isolation run was required. In the all-V2 population, repaired-heuristic aggregate reward fell by 0.074 because it now faced a substantially stronger search bot; against weak V2 it actually gained 0.030. The predeclared aggregate strength gate therefore mixed the quality of two simultaneous changes. The bounded isolation run held every opponent at V1 and showed repaired V2 +0.006, while search V2 gained against both unchanged weak and repaired fields. A first isolated timing read put search at +11.7% ms/decision, just outside the 10% cap, but a consecutive V1/V2 timing replay of the identical workload reversed that noise: V2 was 4.2% cheaper per decision and 23.8% cheaper in total planning time.
