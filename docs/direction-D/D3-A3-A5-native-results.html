02 - Implementation

The single-thread path now owns every rule and policy boundary.

  • A3: explicit pending-kind, player cursor, turn cursor, and decision epoch fields replace the Python generator continuation. Gear/cards remain simultaneous; React, slipstream, and discard remain sequential; stale or duplicate submissions fail before mutation.
  • A4: native code emits the exact 104-float observation, 516-action legal mask, step reward, terminal margin, value-only bootstrap row, state/RNG hash receipt, and fixed boundary receipt. Focused tests compare float and boolean arrays byte-for-byte.
  • A5: the engine decodes all frozen flat action ranges itself and runs successive rounds through completion or the 200-round bound. A canonical 64-bit digest covers compact state, ordered cards, and all 625 MT19937 words for fast lockstep checks.
03 - Design correction

A full-race test found and fixed a real 24-card capacity mistake.

The first two-seat full race stopped in round 11 because repeated spin-outs create new Stress cards. The original 24-card zone bound covered only the starting 18-card deck plus six Heat cards; it did not cover penalty Stress accumulated over a bounded 200-round episode.

The corrected bound is 424 cards per zone: 24 starting cards plus at most two new Stress cards in each of 200 rounds. Zone lengths were widened to 16 bits, the schema hash was bumped to d3-a5-v3-r104-a516-p6-r200-c424-t90, and the debug bridge learned to materialize the expanded arena without enlarging the old D2 tensor hot path. All A0-A5 tests were rerun after this correction.
