A6 - bounded worker pool

The opaque NativePool now owns a fixed number of workers and slots. Admission is atomic, queue and slot overflow fail instead of truncating work, waiting releases the Python GIL, completion frees slots, and one worker fault stops the whole pool. Long test work is cooperatively interrupted so close() can join every owned thread within the checked bound.

A7 - CPU policy coordinator

Ready rows have strict real shapes: 104 observation values, 516 legal-action flags, contiguous decision groups, logical identities, policy IDs, policy versions, and value-only markers. Rows are partitioned by policy identity, so current, snapshot, and anchor models each receive one batch call rather than one Python call per row.

  • keyed_categorical_v1 uses fixed unsigned SplitMix64 operations and frozen receipt words.
  • Reordering whole decision groups preserves actions, log-probabilities, values, and sampling words by immutable decision identity.
  • Bootstrap rows receive values without sampling actions; policy-version drift is rejected.
  • Telemetry records dispatches, inference calls, rows per policy, observed batch-size counts, and inference time.

A8 - compact trajectory arena

The native arena preallocates reusable blocks. Observations remain float32[104]; long-lived masks use nine 64-bit words instead of 516 bytes; scalar fields use compact fixed types. Finalization sorts by game, seat, and decision sequence, omits snapshot/anchor rows from PPO, expands masks in bulk, and returns one contiguous batch.

Terminal rewards and margins close the last row. Truncation folds gamma * V(next) into that row and marks it done, matching the existing collector. The native reverse GAE pass matches RolloutBuffer.compute_gae exactly.

Issue found and fixed. The first native GAE pass used wider intermediate arithmetic and differed from the NumPy oracle by one float32 bit in one value. The reference actually keeps the recurrence in float32. Matching that operation precision removed the mismatch; the test now requires byte-identical advantages and returns.
