02 - Implementation

The work stays separate from the normal CPU package.

  • A0: an optional native/ package builds heat_native._core with MSVC in release or debug mode. Its opaque pool validates exact NumPy dtype, shape, contiguity, and writeability; exposes a versioned receipt; and releases the GIL around native waits.
  • A1: fixed-capacity C++ state stores compact players, tracks, card tokens, zones, spin history, and the complete CPython MT19937 state. The test bridge round-trips through the existing D2/D0 semantic oracle.
  • A2: native code advances cards to the first REACT decision and then handles React/boost movement, traffic, finish, slipstream, corners, heat payment, spin penalties, discard, replenishment, reshuffle, and continuation to the next real decision.

The normal root pyproject.toml and CPU-only install remain compiler-free. Native code is installed separately only when this path is being developed or used.

04 - Measurement correction

One invalid harness result was diagnosed and removed before the final receipt.

The first timing attempt reported 0.032x. Profiling the call path showed that the test-only empty-discard wrapper rebuilt the complete tensor state for every game inside the timed block. That reconstruction is not native rule work and is forbidden from the production boundary. The wrapper now maps discard identities from immutable metadata and performs no state reconstruction.

The focused A2 suite passed after that correction. The full 100k correctness campaign was then rerun under the final source identity, followed by a fresh five-repeat benchmark. The authoritative result is 5.843x; the earlier number is retained here only as a transparent rejected measurement.

05 - Boundaries

This is a hard-slice result, not a complete collector.

  • A3 must add the remaining explicit single-game phases/program counters; A4 adds native observations, masks, rewards, bootstrap rows, and numeric receipts; A5 proves full races.
  • A6-A10 still own workers, queues, batched inference, trajectories, trainer integration, resume, soak testing, and the real trained-transitions-per-second adoption gate.
  • Observations, legal masks, and event receipts were deliberately not claimed by A2 because the design assigns them to A4.
  • No learned-policy generation, CUDA work, large training campaign, eight-hour rehearsal, or final 48-hour run was started.
