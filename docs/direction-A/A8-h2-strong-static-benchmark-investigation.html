01 · Investigation design

The investigation asked whether a stronger fixed player is feasible and where its strength should come from.

ItemPredeclared scope
Primary hypothesisA deterministic simulator-backed player can beat the weak and repaired heuristic fields above chance across generated tracks more reliably than another scalar retune.
Prior confidenceHigh, about 85%, because an older four-player search result existed; lower confidence that the old two-round recipe would transfer unchanged to current A8.
Engineering scopeRead existing agents and run existing or inline diagnostic harnesses. No production-agent changes. One new HTML findings document.
Compute scopeSix screens, each capped at ten minutes with flushed cell-level output. Actual total experiment wall time was about 9.2 minutes.
Data role900000+ is already consumed development data. New 710000+, 711000+, and 712000+ bands become benchmark-development data after this investigation; none is an untouched final test.
Decision ruleRecommend an architecture only if it is deterministic, independent of learned checkpoints, point-estimate above chance with positive placement reward across 2/4/6 seats, and practical for repeatable evaluation.
02 · What already exists

The project has three different notions of “static player.”

PlayerDecision mechanismStrength sourceBenchmark suitability
HeuristicAgentSeparate hand-written gear, card, react, slipstream, and discard rules.Local constants and simple corner checks.Very fast and useful as a floor; too weak to be the main bar.
StrongHeuristicAgentJoint gear/card enumeration with a static one-ply value, forward heat-solvency approximation, relative position, and optional blocking.Better scoring model; still predicts rather than executes the candidate round.Repaired safety baseline, but fresh generated-track strength is inconsistent.
LookaheadAgentClones the exact engine, forces each candidate gear/card plan, simulates forward, averages determinizations, and selects the best line.Rules-correct consequences rather than more evaluator weights.B1-tested style-specific ruler; not globally stronger than weak play.

A fixed search agent is still a static benchmark. Its code and configuration do not learn or change between evaluations. The distinction is computational—several small simulations per move—rather than statistical. That independence is preferable to using a frozen learned checkpoint as the only “strong” ruler, because the benchmark does not inherit the learner’s architecture or training blind spots.

04 · Search architecture investigation

One exact round is more valuable than a deeper approximate rollout.

The first current-rules screen reproduced the broad historical result: two-round determinized lookahead won 40.6% against three weak agents and 47.9% against three repaired strong agents on 24 tight tracks, both above 25% parity. A focused four-player ablation then selected the cheaper one-round configuration.

Search variant vs 3× weakWinsMean placement rewardRoundsDecision costReading
1 round · weak rollout · progress leaf30 / 80 · 37.5%+0.06721.93.44 msSelected
2 rounds · weak rollout · progress leaf21 / 80 · 26.3%−0.08321.46.87 msExtra approximate round hurts
2 rounds · repaired rollout · progress leaf26 / 80 · 32.5%+0.17520.791.25 msBetter placement, disproportionate cost
2 rounds · weak rollout · move-eval leaf9 / 80 · 11.3%−0.50823.56.68 msStatic leaf is actively harmful here

The result identifies the useful mechanism. The exact first round captures candidate speed, corner resolution, traffic blocking, slipstream availability, and random card resolution through the real engine. A second round is driven mostly by an approximate rollout policy, so it adds model error as well as compute. This is why “make the evaluator more complicated” is less attractive than shallow exact simulation.

09 · Limits and cautions

A stronger opponent improves measurement, but cannot define success alone.

  • The freeze hypothesis failed.
    B1 used a new 713000+ frozen development band and 200 games per cell. More sampling is unlikely to reverse the negative weak-field placement rewards.
  • “Strong” is not one-dimensional.
    StaticSearchV1 confidently beats the repaired heuristic but not the weak field. A single ordinal label discards the matchup structure the benchmark is meant to reveal.
  • Non-transitivity is real.
    Results change with homogeneous weak versus repaired fields and with seat count. “A beats B” does not guarantee a total ordering of all agent styles.
  • Evaluation only.
    Filling training games with search opponents would multiply rollout cost and could teach exploitation of a style that B1 did not validate as stronger.
  • Keep multiple rulers.
    B2 now gives equal weight to weak play, repaired scripted play, the opt-in search candidate, and a frozen historical policy while preserving individual results. Its 40-track band is consumed development data, so a later final test still requires untouched tracks. Full B2 result.
