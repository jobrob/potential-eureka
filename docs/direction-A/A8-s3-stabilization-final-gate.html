01 · Completion decision

Auxiliary heads no longer block A8.

A8 already demonstrated useful full-rules learning and held-out transfer with sparse placement reward. The unresolved evidence is checkpoint and seed sensitivity, not failure to extract a learning signal. Adding auxiliary objectives now would change several mechanisms at once and make the final result harder to attribute.

DecisionDefer the remaining Direction-C auxiliary heads. Complete A8 with a frozen checkpoint rule, one directly targeted stabilization comparison, and one untouched final evaluation. Reconsider auxiliary heads only if later evidence identifies representation or credit assignment as the limiting factor.

03 · Frozen candidate

Use the same three-way average for every seed.

G0004 is derived independently from each G0002 run. For run R##, average every floating tensor in @500K, @750K, and @1000K with equal weight. Metadata and non-floating tensors must match exactly. The averaging implementation stores the three source checkpoint identities in the output blob.

G0004-R## = mean(
  G0002-R##@500K,
  G0002-R##@750K,
  G0002-R##@1000K
)

This is a recipe-level rule, not per-seed checkpoint selection. No seed receives a custom window, weight, or validation-driven milestone.

04 · Consumed validation band

Compare G0004 and G0002 on matched races.

The validation experiment reuses the consumed B2 development band at track seeds 714000..714039. Both generations see identical game seeds against weak, repaired-heuristic, StaticSearchV1, and historical G0002-R00 rulers at 2, 4, and 6 seats.

  • Primary stability gate.
    Standard deviation of the three per-run aggregate placement rewards is at most 80% of G0002's matched standard deviation.
  • Skill guard.
    G0004's median aggregate placement reward is no more than 0.030 below G0002.
  • Breadth guard.
    At least three of four ruler-level median differences are non-negative.
  • Selection.
    Adopt G0004 only if all three gates pass. Otherwise retain G0002. The selected generation and its three registered run checkpoints are frozen before opening final-test results.
